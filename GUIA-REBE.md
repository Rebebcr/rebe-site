# Cómo editar rebebcr.com

## Entrar
1. Abra **app.pagescms.org** y entre con el correo al que le llegó la invitación.
2. Elija el proyecto **rebe-site**.

A la izquierda verá tres cosas:
- **Página de inicio**: la página principal.
- **Otras páginas**: páginas nuevas (talleres, programas, eventos…).
- **Ajustes del sitio**: menú, logo, redes sociales, pie de página y códigos de seguimiento.

## Cambiar algo
1. Abra la página y luego **Secciones**. Cada sección aparece cerrada con su nombre; haga clic para abrirla.
2. Cambie textos, fotos o videos.
3. Presione **Save** (Guardar). El sitio se actualiza solo en 1–2 minutos.

> Cada vez que guarda, el sitio se publica. Haga varios cambios y guarde una sola vez al final, no después de cada coma.

## Lo que puede hacer
| Quiero… | Cómo |
|---|---|
| Cambiar un texto | Ábralo y escriba. En los títulos, *entre asteriscos* pone palabras en cursiva dorada. |
| Cambiar una foto | En el campo de la foto, suba una nueva. |
| Ocultar una sección sin borrarla | Desmarque **Mostrar esta sección**. |
| Cambiar el orden | Arrastre las secciones. |
| Agregar una sección | Botón **Add** al final de Secciones → elija el tipo. |
| Agregar un testimonio | Sección *Testimonios* → **Videos** (subir MP4 o pegar enlace de YouTube) o **Testimonios escritos**. |
| Poner un formulario | Agregue la sección **Formulario**, escriba las preguntas y elija el tipo de respuesta. Las respuestas le llegan por correo. |
| Poner Calendly, un mapa o un Google Form | Sección **Código externo** → pegue el código «insertar/embed» que da la herramienta. |
| Crear una página nueva | **Otras páginas** → **Add**. La dirección sale del título: «Talleres 2027» → rebebcr.com/talleres-2027/. Empiece con la sección **Encabezado de página**. |
| Llevar a otra página | Botones, tarjetas de servicios y el menú tienen un campo **Enlace**: `/talleres-2027/` (página del sitio), `#contacto` (sección de inicio) o `https://…` (otro sitio). |
| Agregar enlaces al menú | **Ajustes del sitio** → **Enlaces del menú**. |
| Poner Meta Pixel o Google Analytics | **Ajustes del sitio** → **Códigos de seguimiento**. |

## Consejos
- Videos: MP4 de menos de 20 MB. Para videos largos, súbalos a YouTube y pegue el enlace.
- Fotos: JPG de menos de 1 MB se ven bien y cargan rápido.
- Si algo se ve mal después de guardar, se puede volver a la versión anterior: avísele a Mateo.
